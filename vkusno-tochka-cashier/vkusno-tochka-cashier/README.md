# Кассир «Вкусно — и точка» 🍔

Пиксельная игра в браузере. Картинка, звуки и код уже внутри одного файла `index.html`.

- Заказы приходят на монитор кассы, собери чек и нажми «ВЫДАТЬ»
- Ошибся — клиент оставит отзыв и напишет злое письмо в 📧 Почту
- Копилка, наём персонала (повар, раздатчик, менеджер, уборщик), смены сложнее с каждым разом

## Запуск
Открой `index.html` в браузере и нажми «ИГРАТЬ».

## GitHub Pages
Загрузи `index.html` и `README.md` в репозиторий → Settings → Pages → Deploy from branch → `main` / root.
